## Primary references

### 1. Ali Ali — Director's Portfolio
Official: https://alitwotimes.com/
Portfolio design case study: https://www.behance.net/gallery/98991841/Ali-Ali-Directors-Portfolio

Why it qualifies:
- Ali Ali is a Cairo-based commercials director with multiple Cannes Lions.
- The portfolio itself was recognized with Awwwards Site of the Month, Awwwards Site of the Day, Awwwards Developer Award, FWA of the Day, and Codrops Website of the Week.

What to study:
- minimal typography around highly visual commercial work
- cinematic project sequencing
- restraint: the interface does not compete with the work
- selected-work framing instead of a generic project grid

Relevance to Ahmed: **Very high**

## Synthesis rules for Ahmed

The reference set points consistently toward:
1. selected work, not full archive
2. artwork first, interface second
3. strong identity typography with restrained UI
4. explicit project-type labels
5. asymmetric/editorial sequencing instead of an Instagram grid
6. cinematic pacing where the work supports it
7. motion used to reveal and pace, never to decorate
8. project pages that scale to the amount of real evidence available

## What not to copy

- no clone of Ali Ali's Swiss/minimal system
- no yellow/black clone of O'shane
- no forced experimental navigation from old Awwwards sites
- no WeTransfer visual imitation
- no award-bait interaction that distracts from Ahmed's actual work

The aim is to synthesize principles, then design a visual language that belongs to Ahmed's own work.
