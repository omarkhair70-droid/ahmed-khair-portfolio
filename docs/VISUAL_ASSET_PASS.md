## Homepage image rules

- Never use Behance project covers automatically just because they exist.
- No more than one collage/grid image above the fold.
- Prefer single-image compositions that read in under one second.
- Avoid showing two consecutive projects with the same square social-media template rhythm.
- Alternate visual density: product campaign → automotive → poster → food → beauty.
- Use the strongest art direction first, not the newest work.
- A project with one exceptional image can be a homepage tile without becoming a full case study.
- A project needs at least 3 distinct strong assets to justify a full case-study page.

## Inner-module selection gate

Before reference research or website art direction is locked, collect/export the source images for Tier A projects and score every candidate on:

| Criterion | Weight |
|---|---:|
| Immediate visual impact | 25 |
| Composition / hierarchy | 20 |
| Craft / retouching / lighting | 20 |
| Originality / distinctiveness | 15 |
| Typography integration | 10 |
| Portfolio-scale readability | 10 |

**Hero threshold:** 80/100  
**Supporting threshold:** 70/100  
Anything below 70 is excluded even if it exists on Behance.
