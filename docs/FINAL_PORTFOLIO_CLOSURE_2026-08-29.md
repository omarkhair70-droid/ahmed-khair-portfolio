Verified award recognition includes Awwwards Site of the Month, Site of the Day, Developer Award, FWA of the Day and Codrops Website of the Week.

The site uses dedicated campaign routes because Ali has a large filmography and each selected campaign can carry its own media, description and related films.

### Alexandre Rochet
Awwwards Site of the Day, with additional industry recognition reported by Communication Arts / FWA-era coverage.

The portfolio used case-study routes to carry a very large body of images and video and continuous next-project navigation.

### D Alcausin
Current portfolio uses selected-work detail routes with real project roles, year, descriptions and media.

The relevant lesson is authored project depth when real project-specific material exists.

### Diego Salas
The current portfolio is primarily category-led and image-dense rather than dependent on long narrative case studies.

The relevant lesson is restraint around strong visual work.

## 3. Final route decision

Ahmed's current V1 is different in one important way:

**Home already contains the complete selected evidence for every public project.**

Creating four additional routes now would mostly restage:
- the same 4 BOCH images
- the same 5 Shamadan images
- the same 2 Criminal posters
- the same 2 Coffee images

There is not enough additional verified project-specific material to make those routes materially richer without repetition or invented case-study depth.

Therefore:

**NO dedicated project pages are required for V1 closure.**

Future project routes become valid only when they can add new:
- imagery
- motion/video
- campaign variants
- factual project context
- process evidence
- authored sequence that cannot already live cleanly in Home

## 4. Award-facing benchmark

Awwwards' published Site of the Day scoring frame emphasizes:
- Design
- Usability
- Creativity
- Content

The final Ahmed experience was reviewed against those same dimensions qualitatively.

### Design — PASS
- authored identity Hero
- strong display typography
- disciplined grid / microtype
- project-specific color worlds
- imagery remains the evidence
- no generic portfolio card system
- Home and About share one visual language without becoming duplicates

### Usability — PASS
- simple global navigation
- real Home ↔ About routes
- Work and Contact hashes restore to the actual visible destination
- desktop and mobile layouts
- no horizontal overflow
- keyboard focus
- reduced-motion mode
- Back to top
- verified external Behance action

### Creativity — PASS
- Hero-to-Work handoff
- Work Index interaction
- distinct motion grammar for each project chapter
- controlled use of GSAP / ScrollTrigger / Lenis
- motion supports sequence rather than masking weak static composition
- no unnecessary WebGL / Three / shader layer

### Content — PASS WITH INTENTIONAL CEILING
- only four public projects are shown
- weaker work was removed
- BOCH and Shamadan carry the longest sequences
- Criminal is explicitly a Film Poster Study
- Coffee stays compact
- no fake clients, results, strategy, awards or biography were added

The content quantity is lower than some award-winning reference portfolios, but the curation and presentation do not pretend otherwise.
