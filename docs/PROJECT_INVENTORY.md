# Ahmed Khair Portfolio — Behance Project Inventory

Source profile: https://www.behance.net/ahmedkhairgemy

## Positioning hypothesis

Ahmed's strongest public work is not broad "general graphic design." The most convincing lane is:

**Advertising Visual Design · Social Campaigns · Posters · Photo Manipulation**

The portfolio should lead with visual campaign work and compositing/poster craft, then use product/social-media work as supporting evidence.

## Curation rule

- **Strong** = eligible to lead the portfolio or become a featured case study.
- **Medium** = useful supporting work, or should be merged into a stronger case study rather than shown alone.
- **Drop** = should not appear as a standalone portfolio project in the first release.
